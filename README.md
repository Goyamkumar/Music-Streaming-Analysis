# Music Streaming Analysis

Analysis of a Kaggle Spotify dataset to understand music streaming trends
and how audio characteristics compare across tracks, using Python and Tableau.

## Overview
Led a team to analyze the dataset and compare trends across six key audio
parameters.

## Tech Stack
Python (Pandas, Seaborn, Matplotlib), Tableau, Excel

## Project Structure
- `notebooks/`  Python analysis
- `tableau/`    Tableau workbooks
- `data/`       Datasets (CSV/Excel)



## How to Run
1. Clone the repository
2. `pip install pandas seaborn matplotlib`
3. Open the notebook in `notebooks/` and run all cells
4. Open the `.twb` files in Tableau to view the dashboards
